# B2B Dashboard Plugin

Ce plugin permet d’afficher un tableau de bord B2B personnalisé via un simple shortcode.

## 📦 Installation

1. Téléversez le dossier du plugin dans le répertoire `wp-content/plugins/` de votre site WordPress.
2. Activez le plugin depuis le menu **Extensions** dans l’administration WordPress.

## 🚀 Utilisation

Il suffit de créer une page dans WordPress et d’insérer le shortcode suivant dans un bloc **Shortcode** :

```shortcode
[b2b_dashboard_display]
